# 🚗 Vehicle Rental System

The **Vehicle Rental System** is a web-based application developed to simplify and manage vehicle rental operations. The system allows vehicle owners or rental businesses to maintain vehicle information, register customers, manage rentals, and track the current status of vehicles.

The application provides a centralized dashboard where users can view the total number of vehicles, available vehicles, and currently rented vehicles. Vehicle details such as brand, model, type, registration number, manufacturing year, service date, insurance date, and rental status can be stored and managed efficiently.

The system also includes customer registration and rental management features. Vehicles can be rented and returned through the application, while important vehicle information such as service and insurance dates can be monitored to help ensure timely maintenance and documentation.

## 🎯 Objectives

* To develop an easy-to-use vehicle rental management system.
* To maintain complete information about vehicles.
* To manage customer registration details.
* To track available and rented vehicles.
* To manage vehicle rental and return operations.
* To store vehicle service and insurance dates.
* To reduce manual record keeping and improve data organization.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS
* **Backend:** Python, Flask
* **Database:** SQLite
* **Development Environment:** Visual Studio Code
* **Version Control:** Git and GitHub

## ✨ Main Features

* 📊 Dashboard for vehicle statistics
* 🚗 Vehicle registration and management
* 👤 Customer registration
* 🔑 Vehicle rental and return
* 📋 Vehicle status tracking
* 🛠️ Service date management
* 🛡️ Insurance date management
* 🗃️ SQLite database for storing records
* 🗑️ Vehicle deletion and record management
* 📱 Responsive and user-friendly web interface

## 💡 Purpose

This project demonstrates how a **Python Flask web application** can be combined with an **SQLite database** to create a practical vehicle rental management system. It is designed as an academic/project application and can be further expanded with features such as user authentication, payment management, rental history, automatic service reminders, and reports.
